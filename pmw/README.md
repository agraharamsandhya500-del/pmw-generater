# PWM Generator using Verilog

## Project Description

This project implements a Pulse Width Modulation (PWM) generator using Verilog HDL.

The PWM signal is generated by comparing an 8-bit counter with a programmable duty-cycle value.

## Features

* 8-bit PWM resolution
* Adjustable duty cycle
* Synchronous counter
* Reset input
* Simple RTL design
* Suitable for FPGA simulation

## Inputs

| Signal       |  Width | Description             |
| ------------ | -----: | ----------------------- |
| `clk`        |  1 bit | Clock signal            |
| `reset`      |  1 bit | Reset signal            |
| `duty_cycle` | 8 bits | Controls PWM duty cycle |

## Output

| Signal    | Width | Description          |
| --------- | ----: | -------------------- |
| `pwm_out` | 1 bit | Generated PWM signal |

## Duty Cycle

* `0` → approximately 0%
* `64` → approximately 25%
* `128` → approximately 50%
* `192` → approximately 75%
* `255` → approximately 100%
